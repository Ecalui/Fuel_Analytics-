Problema no Veículo: quando uma viatura consome acima da média independentemente do motorista, o problema é provavelmente mecânico. Quanto mais motoristas diferentes tiverem alto consumo nessa viatura, maior o score de risco.
Problema no Motorista: quando o consumo elevado está ligado a uma pessoa em viaturas diferentes, o padrão aponta para comportamento individual. Se o problema viaja com o motorista, é o motorista.
Problema na Rota: quando o consumo elevado ocorre sempre num destino específico, independente do motorista ou viatura, pode indicar distância real maior do que registada ou desvio sistemático nessa rota.

Metas de Consumo por Marca (L/100km)

Cada marca tem limiares diferentes. ALTO é aviso, CRÍTICO é suspeita confirmada, ROUBO é desvio grave.

Marca Meta (OK) Limiar ALTO Limiar CRÍTICO Limiar ROUBO Registos Usados
Os valores são os limiares superiores de cada categoria. Ex: ALTO de 58 significa que consumo entre 55 e 58 é "ALTO". Acima de 58 é "CRÍTICO".
Rotas com Consumo Elevado Esperado

Quando o Destino contém algum destes termos, o sistema aplica limiares mais altos e usa o prefixo PEDREIRA-* para não confundir com desvios reais da rota normal.

Ex: pedreira, canteira chibia, mina
130 = limiares 30% mais altos nestas rotas
Preços do Gasóleo (Kz/L)

Histórico oficial de preços por data de vigência. Só é possível acrescentar um preço novo a partir de uma data futura — os preços passados são factos históricos e não se editam. Apenas administradores podem alterar.

A partir de Preço (Kz/L)
A data tem de ser posterior ao último preço registado. O preço passa a valer a partir dessa data, para a frente.
Só administradores podem acrescentar preços. Estás a ver o histórico em modo de leitura.
